Diego - Portfólio
Portfólio pessoal desenvolvido para apresentar minha formação, meus estudos e meus projetos na área de tecnologia.
Tecnologias utilizadas
- HTML: estrutura e conteúdo da página.
- CSS: aparência e organização visual.
- JavaScript: interações da página.
- EmailJS: integração planejada para envio de mensagens pelo formulário.
- Google reCAPTCHA: verificação de visitantes no formulário.
Conteúdo do site
- Sobre mim
- Formação
- O que eu estudo
- Meus projetos
- Objetivo
- Formulário de contato
Como executar
1. Baixe ou abra a pasta do projeto.
2. Mantenha index.html, style.css e script.js na pasta correta.
3. Abra index.html no navegador ou use uma extensão/servidor local, como Live Server no VS Code.
4. Antes de publicar, confira as chaves e configurações do EmailJS e do reCAPTCHA.
Arquivos de SEO
- sitemap.xml: lista os endereços públicos que os mecanismos de busca podem descobrir.
- robots.txt: informa regras de rastreamento aos robôs de busca.
Antes de publicar, substitua https://SEU-DOMINIO.com/ em sitemap.xml e robots.txt pelo endereço real do site.
